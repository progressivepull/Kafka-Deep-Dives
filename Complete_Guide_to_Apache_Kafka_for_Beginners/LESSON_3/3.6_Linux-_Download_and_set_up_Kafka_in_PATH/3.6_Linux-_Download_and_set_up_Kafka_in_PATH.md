# 3.6 Linux- Download and set up Kafka in PATH

This lesson explains how to install Java 21 and Apache Kafka binaries on Linux and add Kafka's `bin` directory to `PATH`. The Kafka command-line tools are useful even when Kafka itself runs in Docker with Conduktor.

## Learning Objectives

- Install Amazon Corretto JDK 21 on Linux.
- Download and extract Apache Kafka 4.0 or later binaries.
- Place Kafka in the home directory.
- Configure `PATH` to run Kafka CLI commands from any directory.
- Verify that Java and Kafka commands work.

## 1. Install Java JDK 21

The instructor uses **Amazon Corretto 21**, a production-ready OpenJDK distribution. Choose the installation instructions for your Linux distribution (Debian/Ubuntu, RPM-based, or Alpine).

- Amazon Corretto documentation: https://docs.aws.amazon.com/corretto/latest/corretto-21-ug/what-is-corretto-21.html
- Follow the official repository setup instructions for your distribution, then install Corretto 21.

Verify Java:

```bash
java -version
```

If several Java versions are installed on Debian/Ubuntu, select the intended version using:

```bash
sudo update-alternatives --config java
sudo update-alternatives --config javac
```

## 2. Download Apache Kafka

1. Visit https://kafka.apache.org/downloads.
2. Choose a **binary** distribution of Kafka 4.0 or later, compatible with the course.
3. Download the `.tgz` archive to your Downloads directory.
4. Extract it. Replace the filename below with the actual downloaded filename:

```bash
cd ~/Downloads
tar -xzf kafka_2.13-4.0.0.tgz
```

5. Move the extracted directory into your home directory:

```bash
mv kafka_2.13-4.0.0 ~/
```

> The versioned directory and archive names are examples. Use the actual filenames you downloaded.

## 3. Locate Kafka CLI Tools

Kafka shell scripts are in the `bin` directory:

```bash
cd ~/kafka_2.13-4.0.0/bin
pwd
ls
```

Example Kafka CLI command:

```bash
~/kafka_2.13-4.0.0/bin/kafka-topics.sh --help
```

Without a configured `PATH`, entering `kafka-topics.sh` alone may produce `command not found`.

## 4. Add Kafka to PATH

On Linux systems using Bash, open the Bash startup file:

```bash
nano ~/.bashrc
```

Append the following line (adjust the Kafka directory name):

```bash
export PATH="$PATH:$HOME/kafka_2.13-4.0.0/bin"
```

Save in nano with **Ctrl+X**, **Y**, then **Enter**. Apply the configuration immediately:

```bash
source ~/.bashrc
```

Alternatively, close the terminal and open a new one.

## 5. Verify Kafka CLI Installation

Run:

```bash
command -v kafka-topics.sh
kafka-topics.sh --help
```

The first command should show the location of the script. The second should display Kafka CLI help instead of `command not found`.

> Installing the CLI does **not** start a Kafka broker. If Kafka is already running through Docker and Conduktor, you can use these CLI tools against it. Otherwise, follow the next lecture to start Kafka manually.

## Key Takeaways

1. **Java 21** is the JDK version used in the lecture.
2. **Kafka binaries are needed for the CLI**, even when the Kafka broker runs in Docker.
3. **The `bin` folder contains Kafka `.sh` command scripts** on Linux.
4. **Adding `bin` to `PATH`** avoids typing the full path for every command.
5. **The `.bashrc` file** is used in the lecture because the shell is Bash; other shells have different configuration files.
6. **Kafka 4.0+** uses KRaft rather than ZooKeeper.

## Troubleshooting

- **`java: command not found`:** Check the Java installation and executable path.
- **Wrong Java version:** Use `sudo update-alternatives --config java` on supported Debian-based systems.
- **`kafka-topics.sh: command not found`:** Check the Kafka directory name, the `PATH` entry, and reload `~/.bashrc`.
- **CLI works but cannot reach Kafka:** Verify that the broker is running and that the `--bootstrap-server` address matches its listener configuration.

## Final Result

After completing these steps, you can execute Kafka CLI commands from any directory in a Bash terminal on Linux. You can then connect them to a Kafka broker running locally or through Docker.


## Key concepts
1. Install Java JDK 21: Use Amazon Corretto, a production-ready OpenJDK distribution.

5. Verify installation: Run Kafka CLI commands directly from the terminal.
6. Docker integration: Use the Kafka CLI tools to interact with Kafka running through Docker and Conduktor.

## Example PATH configuration
Add the following line to ~/.bashrc, adjusting the Kafka version to match your installation:

```bash
export PATH="$PATH:$HOME/kafka_2.13-4.0.0/bin"
```

Reload the configuration:

```bash
source ~/.bashrc
```

Verify Kafka CLI:

```bash
kafka-topics.sh --help
```

Key takeaway: Configuring Kafka's bin directory in your Linux PATH allows you to execute Kafka CLI commands from anywhere in the terminal without specifying their full paths.

# 3.7 Linux- Start Kafka in KRaft mode

This lesson explains how to install Java 21, download Apache Kafka binaries on Linux, and configure the `PATH` environment variable so Kafka command-line tools can run from any directory. **Install the CLI tools even if Kafka is already running through Docker and Conduktor.**

## 1. Install Java JDK 21 (Amazon Corretto)

- Visit the [Amazon Corretto documentation](https://docs.aws.amazon.com/corretto/latest/corretto-21-ug/what-is-corretto-21.html).
- Choose **Corretto 21** and the instructions for your Linux distribution: Debian/Ubuntu, RPM-based, or Alpine.
- On Ubuntu, follow the official Debian-based installation instructions to configure the repository and install the JDK.
- Verify installation:

```bash
java -version
javac -version
```

If multiple Java versions are installed on Debian/Ubuntu, select the appropriate one using:

```bash
sudo update-alternatives --config java
sudo update-alternatives --config javac
```

## 2. Download Apache Kafka

1. Open the [official Kafka downloads page](https://kafka.apache.org/downloads).
2. Select a Kafka **4.0 or newer** binary release, as demonstrated in the lecture.
3. Download the binary `.tgz` archive (not the source archive).
4. Extract it, replacing the filename with your actual downloaded archive:

```bash
cd ~/Downloads
tar -xzf kafka_2.13-4.0.0.tgz
mv kafka_2.13-4.0.0 ~/
```

**Note:** `kafka_2.13-4.0.0` is an example directory name; use the version you actually downloaded. The Kafka directory in your home folder contains a `bin` subdirectory with the CLI scripts.

## 3. Add Kafka to the Linux PATH

Without a configured PATH, a command must be invoked with its full or relative path, for example:

```bash
~/kafka_2.13-4.0.0/bin/kafka-topics.sh --help
```

To run it from any directory, edit the Bash configuration:

```bash
nano ~/.bashrc
```

Append the following line, adjusting the directory name:

```bash
export PATH="$PATH:$HOME/kafka_2.13-4.0.0/bin"
```

Save in Nano with **Ctrl+O**, Enter, then **Ctrl+X**. Apply the change without reopening Terminal:

```bash
source ~/.bashrc
```

## 4. Verify Kafka CLI Access

```bash
which kafka-topics.sh
kafka-topics.sh --help
```

If the command resolves to the Kafka `bin` folder and displays help output, the PATH configuration is working. Linux Kafka scripts commonly end with `.sh`.

## 5. Using Kafka with Docker and Conduktor

- **Docker/Conduktor** runs the Kafka broker and provides a graphical interface.
- **Kafka binaries** supply local command-line tools to interact with the broker.
- For a local broker listening on port 9092, a typical command is:

```bash
kafka-topics.sh --bootstrap-server localhost:9092 --list
```

This command requires a running, reachable Kafka broker; installing the CLI alone does not start Kafka.

## Troubleshooting

| Problem | What to check |
| --- | --- |
| `java: command not found` | Complete the Corretto installation and verify the Java selection. |
| Wrong Java version | Run `sudo update-alternatives --config java` on supported Debian/Ubuntu systems. |
| `kafka-topics.sh: command not found` | Confirm the Kafka directory, `bin` path, and `~/.bashrc` entry; run `source ~/.bashrc`. |
| Kafka CLI cannot connect | Ensure Kafka is running and `localhost:9092` matches its configured listener. |
| Downloaded archive name differs | Substitute the actual Kafka version in extraction, move, and PATH commands. |

## Key Takeaways

1. Install **Amazon Corretto JDK 21** and verify with `java -version`.
2. Download and extract **Kafka binaries**, then place the directory in your Linux home folder.
3. Add Kafka's `bin` directory to `PATH` in `~/.bashrc`.
4. Reload Bash settings and verify with `kafka-topics.sh --help`.
5. CLI tools are useful whether Kafka runs locally or through Docker and Conduktor.
6. If you have not started Kafka using Docker, the next lecture covers starting it manually on Linux.

## Key concepts
1. Install Java JDK 21: Use Amazon Corretto, a production-ready OpenJDK distribution.
2. Download Apache Kafka: Download Kafka 4.0 or later from the official Apache Kafka website.
3. Extract Kafka binaries: Place the extracted Kafka directory in your Linux home directory.
4. Configure PATH: Add Kafka's bin directory to ~/.bashrc.
5. Verify installation: Run Kafka CLI commands directly from the terminal.
6. Docker integration: Use Kafka CLI tools to interact with Kafka running through Docker and Conduktor.
